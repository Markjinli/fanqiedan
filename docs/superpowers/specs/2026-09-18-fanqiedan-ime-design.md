# 番茄蛋输入法 — 设计说明

日期：2026-09-18  
仓库：https://github.com/Markjinli/fanqiedan  
包名：`io.github.markjinli.fanqiedan`  
许可：GPL-3.0（与同文一致）

## 背景与目标

做一个独立的开源 Android 中文输入法，底座为同文（Trime / Rime）+ 雾凇拼音全拼。第一版要能给别人从 GitHub 安装使用。

第一版必须具备：

- 个性化短语：编码全词命中后出用户自定义文本
- 语音：长按空格，按屏幕分区选择在线 / 离线 / Openless（Openless 第一版仅占位）
- 模糊音、换肤、emoji

明确不做（第一版）：双拼、链入 Openless 库、主题商店、云同步、Compose 重写同文设置。

## 架构

番茄蛋是同文的产品 fork，一个 Git 仓库、一个 APK。不把同文当 submodule，也不重写 IME 壳。

```
github.com/Markjinli/fanqiedan
  ├── app/                     同文 IME 壳（改包名、应用名、图标）
  ├── librime / JNI            原样保留
  ├── assets/rime/             预置雾凇全拼（rime-ice）
  └── 新增 Kotlin
        ├── phrase/            个性化短语
        ├── speech/            语音路由与三套引擎
        └── theme/             预设皮肤切换
```

与上游关系：git remote `upstream` = `osfans/trime`，需要时再摘修复。Rime 引擎与候选栏不另做一套；短语走 `custom_phrase.txt`，语音识别结果当普通文本上屏。

默认输入方案：雾凇全拼。双拼以后加方案文件，不改引擎。

## 个性化短语

### 命中

雾凇 `custom_phrase.txt`，UTF-8，Tab 分隔：`短语<Tab>编码<Tab>权重`。

| 规则 | 约定 |
|---|---|
| 匹配 | 编码全词命中，前缀不触发 |
| 小写编码 | `[a-z]{1,32}` |
| 大写编码 | 单个 `A`–`Z` |
| 权重 | 默认 100，全词命中时排在普通拼音候选前 |
| 短语正文 | 任意长度。编辑页可多行；写入文件时换行转义为 `\n`（Rime 词表一行一条） |

不在 Java 层做第二套词典。`initial_quality` 保持雾凇高值。

### 大写字母

ASCII 关闭时，`Shift+字母` 作为短语编码，不进入英文。只有用户点「中/英」才进 ASCII。

### 设置页

独立 Activity：列表（关键字、预览、搜索）、编辑、删除、导入/导出（同一文本格式）。

校验：关键字为合法小写串或单个大写字母；关键字不重复；短语非空。

保存：写入用户目录 `custom_phrase.txt`，调用同文已有 Rime Deploy。部署失败则提示「短语已保存，部署失败，可重试」，不回滚文件。

第一版不做：编码含数字/符号、前缀联想短语、候选栏就地编辑、云同步。

## 语音

### 手势

长按空格约 400ms，弹出覆盖层，盖住输入法窗口最下面 30%（从窗口下沿往上算，不含系统导航条）。覆盖期间键盘按键不响应。

分区（占窗口高度比例）：

```
  从下往上 15%–30%： 左半 = 离线 sherpa    右半 = Openless
  最下面 15%：        全宽 = 在线系统识别
```

- 按住空格不移动再松开 → 在线
- 滑入上排左半松开 → 离线
- 滑入上排右半松开 → Openless
- 滑出这 30% 再松开 → 取消

三块有图标和文字，当前块高亮。覆盖层用固定高对比样式，不跟随键盘皮肤。

录音从覆盖层出现时开始；松开时按手指所在块选择引擎。中途换区只换高亮，不切断录音。三块绑定固定，不提供「默认引擎」设置，避免和分区标签打架。

### 引擎

`SpeechEngine` 接口，三套实现：

- `SystemSpeechEngine`：Android `SpeechRecognizer`（通常要网）
- `SherpaSpeechEngine`：sherpa-onnx 端侧
- `OpenlessSpeechEngine`：第一版 stub，松开提示「即将支持」，丢弃音频，不链接 Openless 库（AGPL-3.0，且 Openless 不是 IME）

识别文本作为普通上屏送进 Rime，不当成短语编码。

以后接 Openless：再写一个 Android host 调其核心，仍走 `SpeechEngine`，不把 Tauri 壳塞进输入法。

### 权限与模型

- 第一次使用才申请 `RECORD_AUDIO`
- 离线模型不打进 APK；第一次选离线时下载。未下完就松开 → 提示去设置下载
- 在线失败（无网、无系统识别器、无语音）→ 明确错误，不静默

第一版不做：LLM 润色、必须流式上屏、语音命令（删除/换行）。

## 换肤、emoji、模糊音

### 换肤

设置里 3～5 套预设：浅色、深色、跟随系统（Android 12+ 可用 Monet）、高对比。切换 = 改 theme id + 重载键盘，不 Deploy Rime。进阶可导入一份 `.trime.yaml`。无主题商店、无按应用换肤、无皮肤编辑器。

### Emoji

雾凇 emoji 词表进候选；同文符号/emoji 键保留一个入口。不做贴纸、GIF、搜索大改。

### 模糊音

雾凇已有项做成开关列表（zh/z、ch/c、sh/s、n/l、an/ang 等），写 `*.custom.yaml` 后 Deploy。默认全关。每项带例子。没有「一键全部模糊」，没有韵母组合编辑器。模糊音只作用于普通拼音，不影响短语全词编码。

## 设置信息架构

```
番茄蛋设置
  ├ 个性化短语
  ├ 语音识别（离线模型下载、权限状态）
  ├ 模糊音
  ├ 外观
  ├ 高级（同文原有 Rime 专家项，默认折叠或隐藏）
  └ 关于（GPL-3.0、同文/雾凇致谢、Markjinli）
```

## 错误处理

所有用户可感知失败都用 Toast 或设置页内联文字，禁止静默。

| 场景 | 行为 |
|---|---|
| 短语校验失败 | 编辑页内联错误，不写文件 |
| Deploy 失败 | 文件保留，提示可重试 |
| 麦克风拒绝 | 说明要权限，给到系统设置入口 |
| 在线识别失败 | 说明无网或设备无识别器 |
| 离线模型缺失 | 说明需下载，给到语音设置 |
| Openless | 固定文案「即将支持」 |
| 滑出取消 | 无错误提示，丢弃录音 |

覆盖层在松手或取消后立即关闭，避免挡住输入。

## 测试

自动化（第一版就写，随功能落地）：

- `PhraseStore`：解析/序列化/校验（合法编码、重复关键字、空短语、换行短语）
- 语音热区：给定覆盖层宽高与坐标，断言落在在线 / 离线 / Openless / 取消
- `SpeechRouter`：用 fake engine，断言松开时调用的是对应实现、取消不调用、Openless stub 不上屏

不在第一版做：真机识别准确率、完整 IME 截图回归。装包后的键盘/长按/上屏靠手工清单：

1. 启用番茄蛋，打全拼出字
2. 添加 `addr` 与 `A` 两条短语，全词命中，前缀不命中
3. Shift+A 在中文模式下出短语，中/英切换后仍能打英文
4. 长按空格三区高亮与松手引擎符合分区
5. 滑出取消不上屏
6. 切换浅色/深色皮肤
7. 打开一项模糊音后可打对应混音
8. emoji 词表或符号键能出表情

## 实现顺序

1. Fork 同文，改包名/应用名/图标，编出可安装 APK
2. 预置雾凇全拼，确认能打中文
3. 短语：PhraseStore + 设置页 + Deploy + 大写字母
4. 语音覆盖层热区 + 系统识别 + sherpa 下载与识别 + Openless stub
5. 外观预设、模糊音开关、emoji 入口整理、高级项折叠
6. 单测、手工清单、README、GitHub Release

每一步结束都应有可安装包，而不是最后一次性集成。
